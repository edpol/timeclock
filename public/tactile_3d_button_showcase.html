button.css 
.btn {
  background: linear-gradient(180deg, #6b6bf7, #5656eb);
  color: #ffffff;
  border: 1px solid #4848d6;
  border-radius: 12px;
  padding: 14px 32px;
  box-shadow:
    inset 0  1px 0    #ffffff59,
    inset 0 -2px 0    #0003,
          0  1px 2px  #0006,
          0  8px 24px -6px #5b5bf099;
  transition: translate 0.12s ease, box-shadow 0.12s ease;
}

.btn:active {
  translate: 0 1px;
  box-shadow: inset 0 2px 4px #0004;
}
Notice how :active replaces all 4 outer/bevel shadows with a single inset shadow while shifting the element 1px down.
